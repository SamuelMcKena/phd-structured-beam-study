# Software and Reproducibility

## Audited Environment

- Python: 3.13.7, 64-bit CPython on Windows.
- Mandatory pinned packages: `requirements-report.txt`.
- Optional installed notebook packages: papermill 2.7.0, ipykernel 7.1.0, jupyter 1.1.1.
- Optional palette package installed: colorcet 3.2.1.
- Optional cmocean package: not installed in the audited environment.

Versions are read from installed package metadata and recorded in the freeze manifest. The report
requirements do not invent versions for unavailable optional software.

## Canonical Sources

The fixed hardware manifest is generated by
`vbb_study.digital_twin.phase2a_contracts.canonical_hardware_manifest`. Phase 2A supplies the
controlled family and energy ledgers. Phase 2B reads the Phase 2A route for presentation. Phase 2C
provides independent vector Debye/Fresnel benchmarks. Phase 2E supplies the final source-scale
propagation, metrics and figure pack through
`vbb_study/digital_twin/phase2e_final_source_propagation.py`,
`vbb_study/digital_twin/phase2e_final_source_metrics.py`,
`vbb_study/digital_twin/phase2e_final_source_figures.py` and
`vbb_study/digital_twin/phase2e_final_figure_style.py`. `vbb_study/solver_policy.py` governs later
claim-driven selection without changing those solvers.

## Numerical Precision

NumPy/SciPy operations use the dtype established by each solver. Phase 2A stores propagated intensity
stacks as `float32` while power and report metrics are accumulated/exported as Python/NumPy floating
values. Phase 2C complex vector calculations and exported metrics use double-precision complex/float
working arrays unless a source explicitly states otherwise. The freeze hashes outputs rather than
relying on rounded prose values.

## Phase 2E Production Tools

The Phase 2E numerical results and figure pack were produced by:

```powershell
C:\PhD\.venv2\Scripts\python.exe tools/run_phase2e_final_source_propagation.py
C:\PhD\.venv2\Scripts\python.exe tools/build_phase2e_final_figure_pack.py
```

These are expensive optical runs and are recorded here for provenance only. The accepted Phase 2E
outputs under `outputs/validation/phase2e_final_propagation/` and
`outputs/figures/phase2e_final_source_propagation/` are frozen evidence. Do not re-run these tools to
verify a report freeze; verification is by hash comparison against the frozen manifest.

The selected production run used N=3072 on a 10 mm window with dz=0.25 mm over z=0-180 mm, an
estimated peak memory of 1.146 GiB, and a total gate/convergence/production runtime of 8,696.75 s.

## Reproducibility Boundary

Bitwise figure/PDF reproduction may depend on OS fonts, plotting backends and PDF metadata. Report
metrics must come from governed CSV/JSON/native arrays, not pixels. Passing tests confirms software
and numerical contracts but is not evidence of experimental agreement.
