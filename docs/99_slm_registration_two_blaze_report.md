# Sub-pixel registration of dual-SLM vortex-Bessel beams with blaze on both panels

## Status

This document supersedes the earlier one-blaze architecture interpretation.

The corrected study contract is:

- Architecture A: SLM1 = vortex + 20-pixel blaze; SLM2 = correction + 20-pixel blaze.
- Architecture B: SLM1 = correction + 20-pixel blaze; SLM2 = vortex + 20-pixel blaze.

The report evidence is generated by the SLM registration report workflow.
The focused physics/contract tests are generated by the SLM registration
architecture workflow.

At the current flat-correction effective-channel level, the two physical panels
have no measured panel-specific transfer inserted between them. Therefore
exchanging which panel owns the vortex is a panel relabelling. The code enforces
this with the architecture label symmetry evidence; an apparent A/B winner in
this limit is treated as a model failure rather than a physical result.

## Research question

How sensitive is the dual-SLM structured-beam route to the sub-pixel position of
the optical field/hologram relative to the physical 8 um SLM lattice, and how
does that sensitivity change with:

- topological charge,
- beam radius on the SLM,
- x versus y registration,
- whether the shifted panel carries vortex + blaze or blaze/correction only,
- propagation through the 4F route and physical axicon?

A second question - whether generating the vortex on SLM2 is practically more
robust than generating it on SLM1 - is intentionally deferred until the model
contains measured panel-specific information capable of breaking the present
A/B symmetry.

## Pure registration definition

For a selected panel, the registration displacement d is implemented as

~~~
panel_translation = -d
pattern_offset     = +d
~~~

so the beam-to-hologram centring remains unchanged and only the position of the
beam/hologram relative to the physical pixel lattice changes.

Representative offsets are fractions of the 8 um pitch:

~~~
0, 1/8, 1/4, 3/8, 1/2 pixel
= 0, 1, 2, 3, 4 um
~~~

The deterministic geometry diagrams are generated by:

~~~
python tools/plot_slm_registration_geometry.py
~~~

They show the fixed beam/hologram centre and the physical lattice moving
underneath it, including reference, quarter-pixel, half-pixel edge and
half-pixel corner examples.

## Corrected two-blaze scalar route

Each displayed phase command contains its panel's carrier/blaze.

For Architecture A:

~~~
phi_1 = phi_vortex + phi_blaze,1
phi_2 = phi_correction + phi_blaze,2
~~~

For Architecture B:

~~~
phi_1 = phi_correction + phi_blaze,1
phi_2 = phi_vortex + phi_blaze,2
~~~

In the current scalar effective-channel representation the two phase ramps are
sequential phase terms. The common 4F selected-order centre is therefore
computed from the summed scalar carrier. The code rejects numerical windows
that would clip the selected order or iris after this two-blaze correction.

The canonical hardware constants used by the evidence run are:

- wavelength: 1029 nm,
- SLM pitch: 8 um,
- SLM phase levels: 256,
- fill factor: 0.93,
- blaze/carrier: 6.25 lp/mm = 20 pixels per period on each SLM,
- 4F focal length: 300 mm,
- physical axicon base angle: 2 degrees,
- refractive index: 1.458,
- canonical beam radius: 2 mm = 250 pixels.

## Evidence runs

### Mechanism study

The corrected evidence workflow uses a resolved 10 mm fine window with
N = 2500, i.e. 4 um sampling = 2 samples per 8 um pixel, and compares:

- L = 10 and 20,
- beam radii w = 50 and 100 pixels,
- x and y half-pixel registration,
- SLM1-only and SLM2-only registration,
- both phase-allocation labels.

Representative XY fields are retained before the physical axicon and at a
matched propagated plane after the axicon.

### Canonical-bench control

A separate run uses:

- w = 250 pixels = approximately 2 mm,
- L = 10 and 20,
- x and y half-pixel registration,
- the same two-blaze contract.

## Symmetry result

With flat correction and no measured inter-SLM transfer, equivalent panel roles
match to numerical precision. The generated report evidence gives B/A = 1 for
the paired vortex-owner cases at every generated L and beam radius, with the
paired metric differences at numerical round-off.

Therefore:

> The current effective-channel model is suitable for quantifying local
> vortex+blaze and blaze-only registration sensitivity, but it cannot determine
> whether the real bench is intrinsically more robust with the vortex generated
> on SLM1 or SLM2.

To answer the architecture-ranking question physically, the next model layer
must include measured panel-specific information, for example:

- SLM1-to-SLM2 free-space or relay transfer,
- relative parity/rotation/magnification,
- panel-specific LUT/calibration,
- measured correction phase map,
- measured static panel phase/fringing where available.

## Quantitative findings

The cleanest local comparison is between the panel that carries vortex + blaze
and the other panel carrying only the blaze plus the flat correction baseline.

For a half-pixel x shift, Architecture A can be read as:

- SLM1 = vortex+blaze role,
- SLM2 = non-vortex blaze role.

Architecture B gives the same values after swapping panel labels.

### L = 20

At w = 50 pixels:

- vortex+blaze raw infidelity = 0.267,
- vortex+blaze centroid-recentred infidelity = 0.964,
- non-vortex blaze raw infidelity = 1.61e-3.

The propagated peak intensity at the matched post-axicon plane falls to about
4.0% of the zero-registration reference for the vortex-owning half-pixel shift.
This is a deliberately severe small-beam/high-charge mechanism case.

At w = 100 pixels:

- vortex+blaze raw infidelity = 6.62e-3,
- vortex+blaze centroid-recentred infidelity = 1.21e-2,
- non-vortex blaze raw infidelity = 4.23e-5.

At the canonical w = 250-pixel beam:

- vortex+blaze raw x-shift infidelity = 3.02e-5,
- vortex+blaze centroid-recentred infidelity = 2.73e-3,
- vortex+blaze raw y-shift infidelity = 1.48e-5,
- non-vortex blaze raw x-shift infidelity = 9.85e-6.

The matched post-axicon peak intensity changes by only about 2.1%, and the
Bessel-zone FWHM is unchanged at the axial sampling used by the study.

### L = 10

At w = 50 pixels the raw x-shift infidelity is only 6.88e-5 for the
vortex+blaze role. At w = 250 pixels it is 5.46e-6.

Thus the current approximately 2 mm beam is much less sensitive to pure
sub-pixel registration than the intentionally compressed high-charge test beam.

## Directionality

The carrier/blaze is x-directed in the present convention, so x and y
registration are not equivalent.

For L = 20, w = 50 pixels:

- vortex+blaze raw x-shift infidelity = 0.267,
- vortex+blaze raw y-shift infidelity = 0.109.

At w = 250 pixels the same values fall to approximately 3.02e-5 and 1.48e-5.

This makes x/y sweeps a required part of the experimental validation.

## Qualitative error signature

The generated XY fields show that registration is not best diagnosed by asking
whether a ring simply looks worse. The useful signature is the matched signed
residual relative to zero registration, together with centroid, peak intensity
and axial metrics.

The report therefore uses:

- pre-axicon XY intensity,
- pre-axicon signed residual,
- propagated post-axicon XY intensity,
- propagated signed residual,
- raw and centroid-recentred field infidelity,
- peak intensity ratio,
- Bessel-zone FWHM ratio.

The physical axicon is phase-only in the model, so after-axicon intensity
figures refer to a propagated plane after the axicon rather than the immediate
post-surface intensity.

## Interpretation

Three conclusions are supported by the corrected evidence.

1. The high-charge vortex is locally sensitive to pixel registration when it is
   compressed onto relatively few SLM pixels. The effect grows strongly as
   beam radius decreases.

2. The present approximately 2 mm beam is comparatively tolerant. Sub-pixel
   registration produces measurable complex-field/residual changes but does not
   grossly destroy the propagated Bessel-region intensity in the current model.

3. The present flat-correction effective-channel model cannot establish a real
   SLM1-vortex versus SLM2-vortex winner. Both panels are blazed and the two
   phase allocations are exactly symmetric when panel-specific propagation and
   calibration are absent.

## Required next experimental/model step

To test the original architecture hypothesis rather than only local
registration sensitivity, measure or otherwise fix the actual SLM1-to-SLM2
transfer and insert it into the digital twin. At minimum this should establish:

- physical/optical separation or relay prescription,
- image parity and any rotation,
- transverse magnification,
- carrier direction/sign convention at each panel.

Then repeat exactly the same registration matrix with the measured correction
map on SLM1 for the downstream-vortex architecture. The existing runner,
metrics, XY plotting and report-evidence pipeline are structured so that this
additional realism layer can be added without redefining registration itself.
